🛠️ Make your own extension

An extension is just a folder with a manifest.json file and some HTML, CSS and JavaScript. Try it:

  1. Make a new folder, for example my-first-extension.
  2. Inside it, make a file called manifest.json with this in it:
{
  "manifest_version": 3,
  "name": "My first extension",
  "version": "1.0",
  "content_scripts": [{
    "matches": ["https://*/*"],
    "css": ["style.css"]
  }]
}
  1. Make a file called style.css next to it, with body { background: lightyellow !important; }
  2. Press the button below and pick your folder. Every website now has a yellow background! Change the CSS, then press Reload on your extension.
